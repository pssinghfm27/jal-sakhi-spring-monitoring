## जल साखी ऐप: रीडिंग दर्ज करने के 5 कदम

### 1. ऐप खोलें और GPS चालू करें
   - फ़ोन का GPS / Location ON करें।
   - ऐप में accuracy हरी (✓ < 20 m) होने तक रुकें।

### 2. स्रोत चुनें (Spring चुनें)
   - "नई डिस्चार्ज" / "नई जल गुणवत्ता" पर टैप करें।
   - ड्रॉपडाउन से अपने गाँव का स्रोत चुनें।
   - **कभी भी नया नाम न लिखें** — सूची से ही चुनें।

### 3. माप लें
   **डिस्चार्ज:**
   - V-notch / Volumetric / Float — विधि चुनें।
   - L/min में मान दर्ज करें + अवधि (sec)।
   - मौसम: सूखा / हल्की बारिश / भारी बारिश / पोस्ट-मानसून।

   **जल गुणवत्ता (8 पैरामीटर):**
   - pH, TDS, टर्बिडिटी, हार्डनेस, क्षारीयता, क्लोराइड, आयरन, फीकल कोलिफ़ॉर्म।
   - हर बॉक्स के नीचे BIS रेंज दिखेगा — हरा/पीला/लाल संकेत देखें।
   - किट batch ID और expiry date भी डालें।

### 4. फ़ोटो ज़रूरी है
   - V-notch / kit / strip का स्पष्ट फ़ोटो लें।
   - चाहें तो 30 सेकंड का voice note जोड़ें।

### 5. Save दबाएँ
   - Offline भी काम करेगा — डेटा फ़ोन में सेव हो जाएगा।
   - इंटरनेट आते ही **Sync** अपने आप होगा।
   - Sync स्क्रीन पर "0 pending" दिखे = सब upload हो गया।
