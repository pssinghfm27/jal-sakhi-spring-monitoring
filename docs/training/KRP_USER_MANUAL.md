## 1. Install the app / ऐप इंस्टॉल करें

You will receive `jalsakhi.apk` from your CHIRAG manager via **WhatsApp**.
आपको CHIRAG मैनेजर से WhatsApp पर **`jalsakhi.apk`** मिलेगा।

**Steps:**
1. Open WhatsApp and tap the APK file / WhatsApp में APK फ़ाइल पर tap करें
2. Your phone will ask: *"Allow install from this source?"* — tap **Settings → Allow** / "इस स्रोत से इंस्टॉल करें?" — **Settings → Allow** टैप करें
3. Tap **Install** / **Install** टैप करें
4. Tap **Open** when done / पूरा होने पर **Open** टैप करें

## 2. Create your account / अपना अकाउंट बनाएँ

When you open the app for the first time, you'll see the **Login** screen.
पहली बार ऐप खोलने पर **Login** स्क्रीन दिखेगी।

Tap **"New KRP? Create account"** at the bottom.
नीचे **"New KRP? Create account"** पर tap करें।

Fill the signup form / साइनअप फॉर्म भरें:

| Field / फ़ील्ड | What to enter / क्या डालें |
|---|---|
| **Name / पूरा नाम** | Your full name as in CHIRAG records / CHIRAG रिकॉर्ड के अनुसार पूरा नाम |
| **Mobile / मोबाइल नंबर** | Your 10-digit mobile number / 10 अंकों का मोबाइल नंबर |

## 6. Record discharge / डिस्चार्ज दर्ज करें

Tap **💧 Record Discharge / डिस्चार्ज दर्ज करें** on home screen.

### Step 1: Wait for GPS / GPS का इंतज़ार करें

The app needs **accurate GPS** before you can save. Stand in open sky (away from trees / walls).
ऐप को **सही GPS** चाहिए। पेड़ों / दीवारों से दूर खुले आसमान में खड़े हों।

| GPS status / GPS स्थिति | Meaning / मतलब |
|---|---|
| 🟡 "GPS locating..." | Wait 10-30 seconds / 10-30 सेकंड रुकें |
| 🟢 "GPS accuracy: 8.5 m" | ✅ Ready to save / सहेजने के लिए तैयार |
| 🔴 "GPS accuracy worse than 20 m" | Move to open area / खुली जगह जाएँ |

### Step 2: Select Spring / स्रोत चुनें

Tap the **Spring** dropdown → list of your village's springs appears.
**Spring** ड्रॉपडाउन पर tap करें → आपके गाँव के स्रोतों की सूची दिखेगी।

Pick the spring you're measuring. **Never type a spring name.**
जिस स्रोत को मापा रहे हैं उसे चुनें। **कभी भी स्रोत का नाम न लिखें।**

### Step 3: Fill measurement / मापन भरें

| Field | Enter |
|---|---|
| **Method / विधि** | Tap one: V-notch / Volumetric / Float |
| **Discharge / डिस्चार्ज (L/min)** | Your measured flow in litres per minute |
| **Duration / अवधि (sec)** | How long you measured for |
| **Weather / मौसम** | Tap one: Dry / Light rain / Heavy rain / Post-monsoon |

### Step 4: Take photo / फ़ोटो लें

Tap **📷 Take photo / फ़ोटो लें**. Camera opens.
Take a **clear photo of your V-notch / measuring container / float setup**.
V-notch / नापने का बर्तन / float का **स्पष्ट फ़ोटो** लें।

📷 **Photo is required** — you cannot save without it.
**फ़ोटो ज़रूरी है** — इसके बिना सहेज नहीं सकते।

### Step 5: Optional / वैकल्पिक

- **Notes / टिप्पणी** — anything unusual about today's reading
- **Voice note / वॉइस नोट** — 30 seconds max (coming soon)

### Step 6: Save / सहेजें

Tap the big green **Save / सहेजें** button at the bottom.
नीचे बड़ा हरा **Save / सहेजें** बटन दबाएँ।

You'll see: ✅ **"Saved locally — will sync when online"**
दिखेगा: ✅ **"लोकल सहेजा गया — ऑनलाइन आते ही सिंक होगा"**

## 7. Record water quality / जल गुणवत्ता दर्ज करें

Tap **🧪 Record Water Quality / जल गुणवत्ता दर्ज करें** on home screen.

The same GPS gate and spring picker apply (see section 6).
GPS और स्रोत चुनने का तरीका वही है (खंड 6 देखें)।

### The 8 parameters / 8 पैरामीटर

Test your sample with the kit, then enter each value.
किट से नमूना जाँचें, फिर हर मान दर्ज करें।

| Parameter | BIS range | Color cue |
|---|---|---|
| **pH** | 6.5 – 8.5 | 🟢 in range • 🟡 borderline • 🔴 unsafe |
| **TDS** (mg/L) | 0 – 500 (max 2000) | same |
| **Turbidity** (NTU) | 0 – 1 (max 5) | same |
| **Total Hardness** (mg/L) | 0 – 200 (max 600) | same |
| **Alkalinity** (mg/L) | 0 – 200 (max 600) | same |
| **Chloride** (mg/L) | 0 – 250 (max 1000) | same |
| **Iron** (mg/L) | 0 – 0.3 | same |
| **Fecal Coliform** (MPN/100ml) | 0 only | 🟢 if 0 • 🔴 any > 0 |

**As you type, the color of each box changes automatically.**
**जैसे ही आप टाइप करते हैं, हर बॉक्स का रंग अपने आप बदलता है।**

🔴 **Red?** Tell your block coordinator immediately. / **लाल?** तुरंत ब्लॉक कोऑर्डिनेटर को बताएँ।

### Test kit info / किट की जानकारी

| Field | Enter |
|---|---|
| **Kit Batch ID / किट बैच ID** | Number printed on the test kit box |
| **Kit Expiry / किट एक्सपायरी** | Date printed on the box (YYYY-MM-DD) |

⚠️ If the date is in the past, app will warn: **"This kit is expired"**.
⚠️ यदि तारीख बीत चुकी है, चेतावनी मिलेगी: **"यह किट एक्सपायर है"**।

### Photo of test result / परीक्षण परिणाम का फ़ोटो

Tap **📷 Take photo / फ़ोटो लें** — capture the test strip / kit result clearly.
**स्पष्ट** फ़ोटो लें — टेस्ट स्ट्रिप / किट का परिणाम।

Tap **Save / सहेजें**.

## 9. Sync status / सिंक स्थिति

Tap **☁️ Sync Status / सिंक स्थिति** on home screen.

You'll see:
- **"X records pending sync" / "X रिकॉर्ड सिंक के लिए बाक़ी"** — these are saved but not yet uploaded
- **Last sync time / पिछला सिंक** — when the app last reached the CHIRAG server

| Status | Meaning |
|---|---|
| 0 pending | ✅ All your readings are on the CHIRAG server |
| 1+ pending | ⏳ Still offline — go to a place with internet, app will sync automatically |

You can also tap **Sync Now / अभी सिंक करें** to force immediate upload.
**Sync Now / अभी सिंक करें** पर tap करके तुरंत अपलोड कर सकते हैं।

## 11. Common problems / आम समस्याएँ

### "GPS accuracy worse than 20 m" / GPS सटीकता खराब
- **Move to open sky** — get away from buildings, trees, hills
- **खुले आकाश में जाएँ** — इमारतों, पेड़ों, पहाड़ों से दूर
- Turn phone GPS **OFF and ON** again
- फ़ोन GPS **बंद करके चालू करें**
- Wait up to 1 minute / 1 मिनट तक रुकें

### "Login failed: Invalid credentials" / लॉगिन विफल
- Check phone number — must be **10 digits**, no spaces
- नंबर जाँचें — **10 अंक** होने चाहिए, बिना space
- Check password is correct (case-sensitive)
- पासवर्ड सही जाँचें (बड़े-छोटे अक्षर अलग होते हैं)
- If you forgot password, **call block coordinator**
- पासवर्ड भूल गए तो **ब्लॉक कोऑर्डिनेटर को कॉल करें**

### "Awaiting manager approval" / मैनेजर की अनुमति का इंतज़ार
- Wait 24 hours / 24 घंटे रुकें
- After 24 h, call your block coordinator / 24 घंटे बाद ब्लॉक कोऑर्डिनेटर को कॉल करें

### "Network error" / नेटवर्क त्रुटि
- Check if you have mobile data or Wi-Fi / मोबाइल डेटा या Wi-Fi जाँचें
- Your readings are **safe** — they're saved on your phone and will sync when internet comes back
- आपके रिकॉर्ड **सुरक्षित** हैं — फ़ोन में सहेजे गए हैं, इंटरनेट आते ही सिंक होंगे

### Photo doesn't save / फ़ोटो सहेज नहीं होता
- Open phone Settings → Apps → Jal Sakhi → Permissions → enable **Camera** + **Storage**
- फ़ोन Settings → Apps → Jal Sakhi → Permissions → **Camera** + **Storage** चालू करें
