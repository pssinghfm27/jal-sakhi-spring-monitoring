1Enter your CHIRAG server URL

This is where the backend (Postgres + API) is running. Usually http://<your-ip>:8080 in a pilot, or https://api.chirag.example.org in production.

2Share with KRPs

Show this QR code to a KRP holding the Jal Sakhi app. They can scan it on the first-run Server Setup screen instead of typing the URL.

Enter a URL above

How a KRP joins:

  1. Install the APK on their Android phone.
  2. On first launch, the "Server Setup" screen appears.
  3. Type the URL or scan this QR code.
  4. Receive OTP by SMS, sign in.
  5. Start recording springs offline — data syncs when online.

A KRP can change the server later via "Change server URL" on the login screen.

3Build the APK

Run this on the same machine that has Android Studio installed.

# default: KRP picks URL at first launch
./build-apk.sh

# or pre-bake the URL so the setup screen is skipped:
./build-apk.sh

Output lands in dist/jalsakhi-debug-YYYYMMDD-HHMM.apk — send via WhatsApp/Telegram or adb install.

4Start the backend (if not already running)

./start-server.sh

Spins up Postgres + the API in Docker, runs migrations, seeds demo data, and prints the URL you should use above.
